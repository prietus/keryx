# Keyboard shortcuts

## Moving around

| Keys | |
| --- | --- |
| ++cmd+k++ | Go to a conversation, or run a command |
| ++cmd+alt+up++ / ++cmd+alt+down++ | Previous / next conversation |
| ++cmd+alt+shift+down++ | Next unread |
| ++cmd+shift+w++ | Close conversation |
| ++cmd+shift+r++ | Mark all as read |
| ++cmd+alt+0++ | Show or hide the member list |

## Finding

| Keys | |
| --- | --- |
| ++cmd+f++ | Find in conversation |
| ++cmd+shift+f++ | Search all history |
| ++cmd+shift+m++ | Mentions of you |

## View

| Keys | |
| --- | --- |
| ++cmd+plus++ / ++cmd+minus++ | Bigger / smaller text |
| ++cmd+shift+p++ | Privacy mode |
| ++cmd+alt+l++ | Network protocol log |
| ++cmd+comma++ | Settings |

## Composer

| Keys | |
| --- | --- |
| ++tab++, ++right++ | Accept the suggestion (Tab cycles) |
| ++alt+s++ | Fix the nearest typo |
| ++up++ / ++down++ | Input history |
| ++shift+enter++ | New line |
| ++esc++ | Cancel a reply |

## Networks

| Keys | |
| --- | --- |
| ++cmd+shift+n++ | New network |
